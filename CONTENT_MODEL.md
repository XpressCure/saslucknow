# Content model

All publishable entries share `title`, `slug`, `language`, `status`, SEO metadata, author/editor references and timestamps. Rich content is stored as sanitised structured blocks rather than arbitrary HTML.

Homepage composition is setting-driven: hero, featured quotation, event, lecture, section visibility/order and calls to action. Organisation name, tagline, contact details, disclaimer and contribution terminology are settings—not page constants.

Resource types are article, lecture, audio, video, quotation, reflection, book extract and study material. Every quotation includes source/reference fields and a verification status. Placeholder quotations must never be published as verified.

Media records include S3 key, MIME type, byte size, alt text, caption, tags, folder and usage references.
