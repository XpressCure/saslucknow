# Administration guide

Administrators will manage site identity and contact settings, bilingual pages, people and timelines, resources, quotations, topics, events, registrations, community members, volunteers, shrine media and enquiries.

Recommended roles are Super Administrator, Administrator, Content Editor, Event Manager, Finance Manager and Viewer. Finance access should be separated from editorial access. Every publish, delete, settings and payment-related action must create an audit record.

Before launch, replace all placeholder content; verify every quotation and media permission; add approved privacy, terms, contribution and refund policies; confirm affiliation wording; and test notification consent separately from event registration.
