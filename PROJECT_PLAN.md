# Project plan

## Phase 1 — Foundation and public experience

- Bilingual English/Hindi public interface, responsive navigation and accessible design tokens.
- Home, introductions, wisdom library, events, shrine, community, contact and policy content.
- MongoDB repositories, protected administration, form validation, rate limiting and audit records.
- Event registration, community, volunteer, contact and newsletter workflows.

## Phase 2 — Operations

- Razorpay order creation, signature-verified webhooks and receipts.
- S3 media library with signed uploads, file validation and usage tracking.
- Registration CSV exports, email delivery and editable site settings.

## Phase 3 — Learning and membership

- Member accounts, study circles, structured Savitri paths and progress tracking.

The current build implements the complete visual foundation and interactive critical journeys with safe demonstration submissions. Production persistence, authentication and payments are integration-ready but require deployment credentials and legal content approval.
