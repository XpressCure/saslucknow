# Sri Aurobindo Society, Lucknow

A bilingual, mobile-first spiritual and educational community platform for Lucknow and the Sultanpur shrine.

## Technology

React 19, TypeScript, Next-compatible App Router and Node.js. The production architecture targets MongoDB, Amazon S3, Razorpay and AWS EC2. The included preview uses safe demonstration form completion until production credentials and policies are supplied.
